工作原理

三步搞定，无需输入

安装完成后，整个流程自动运行 — 你只需播放视频即可。

1

安装浏览器扩展

TrackLay Sync 在 Chrome 或 Brave 中静默运行，只读取 YouTube 上正在播放的视频信息。

2

打开 TrackLay 应用

应用从扩展接收视频信息，查找曲目列表并生成叠加层 — 全自动完成。

3

添加到 OBS

将叠加层链接粘贴到 Browser Source 中即可。完成 — 你的直播现在会显示正确的曲目。

功能特色

专为长时间 DJ 直播打造

每一个细节都为音乐直播而设计 — 无论是单曲还是长达两小时的整场演出。

我们的核心优势

专为长时间直播打造

与常规音乐叠加工具不同，TrackLay 专为长时间直播（long sets）打造。它能自动从 YouTube 视频描述或置顶评论中提取完整的曲目列表信息，让你的直播数小时内保持完美同步。

自动曲目列表

TrackLay 会读取视频描述，必要时还会读取评论区，以识别整场演出中的每一首曲目。

始终保持同步

扩展会跟随视频的真实播放时间，因此曲目会在正确的时刻切换 — 即使是长达一小时的演出也不例外。

7 种现成主题

简约、卡片、赛博朋克、冰霜、星系、黄金时刻和广播条。一键切换。

自定义颜色与字体

直接在应用中调整颜色、大小、字体（支持 Google Fonts）和对齐方式 — 无需编辑代码。

轻量级扩展

只读取正在播放的视频。无需 Tampermonkey，无需额外配置 — 安装即可使用。

原生 Windows 应用

单一窗口，内存占用低 — 不会与直播的其他部分争抢系统资源。
